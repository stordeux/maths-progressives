🧮 Maths progressives

Des exercices qui s'adaptent à toi : le niveau monte quand tu réussis, redescend quand c'est trop dur. Un cours à chaque niveau, des indices, un brouillon.

Ma progression

Ta progression reste sur cet appareil (elle n'est jamais envoyée sur Internet). Pour la passer sur un autre appareil, exporte-la puis importe-la là-bas.

Tout recommencer à zéro ? Les niveaux, les étoiles et les scores de tous les modules seront effacés sur cet appareil, et ton titre redeviendra « Stagiaire ». Les réglages sont gardés.
Conseil : exporte d'abord ta progression si tu veux pouvoir la retrouver. Pour un seul module, utilise « Remettre ce module à zéro » dans le menu Niveaux du module.

Recopie ce code sur l'autre appareil (bouton « Importer »), ou enregistre le fichier.

Colle un code de progression, ou choisis un fichier .json exporté.

Fonctionne sans connexion après la première visite. Sur tablette : menu du navigateur → « Ajouter à l'écran d'accueil ».
